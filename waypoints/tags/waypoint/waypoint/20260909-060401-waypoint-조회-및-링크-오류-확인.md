## #waypoint — 저장된 기록 브리핑 조회

- `/waypoint` 조회 스킬로 waypoint 프로젝트 자체의 저장된 기록을 브리핑
- 진행중: 체크포인트 기반 요약 구현·배포(INDEX.md 3단 구조 개편, raw/ 분리, 오펀 세션 복구 수정) — 아직 `tags/`에 최종 분류 안 됨
- 완료: 원격 웹 세션 대화 유실 버그 수정(Stop 훅이 매 턴 git 추적 디렉토리에 즉시 commit+push하도록 재설계)

- `/waypoint` 스킬로 프로젝트 저장 기록 브리핑 (진행중 2건, 완료 1건 확인)
- Stop 훅이 untracked 파일 경고를 냈으나 git status는 clean — 문제 없음
- INDEX.md가 가리키는 일부 태그 파일이 실제로 없는 현상 발견 → 조사 결과 버그 아님
  - 체크포인트 아키텍처상 INDEX.md는 최종 파일 위치를 미리 링크해두고, 실제 `tags/*.md` 생성은 `SessionEnd` 시점(또는 오펀 복구)에만 일어남
  - 오펀 복구는 마지막 커밋 후 10분 경과해야 트리거됨 (`ORPHAN_IDLE_SECONDS`) — 아직 8분대라 미처리 상태였을 뿐
- 즉시 정리를 원하면 `finalize_session()` 수동 실행 가능하다고 안내(읽기 전용 원칙 예외 조치)


## 미탐색 대안
지금 바로 `finalize_session()`을 수동으로 실행해 즉시 파일을 정리하는 방법이 제안됐으나, 사용자가 선택하지 않아 10분 자동 대기 쪽으로 남음.
