# Waypoint

Claude Code로 작업하다가 다룬 여러 접근법·주제가 대화가 끝나면 같이
사라지는 문제를 해결하는 보조 도구입니다. AI 자체가 아니라, AI를 더
효율적으로 쓰게 도와주는 유틸리티입니다.

## 뭘 해주나요

- 대화가 진행되는 동안 자동으로 내용을 기록합니다 (`waypoint`).
- 세션이 끝나면 AI가 그 기록을 태그별로 분류해서 정리합니다.
- 다음에 같은 프로젝트에서 새 세션을 시작하면, 아직 끝나지 않은
  작업이 있는지 자동으로 알려줍니다.
- `/waypoint` 스킬로 지금까지 쌓인 기록을 조회할 수 있습니다 (브리핑,
  ADR 생성, 비슷한 과거 사례 찾기, 반복 패턴 추출, 통계 리포트 등).

사용자는 세션을 언제 끝낼지, 어디에 저장할지 신경 쓸 필요가 없습니다 —
전부 자동으로 처리되고, 전부 이 저장소(git)에 커밋됩니다.

## 동작 원리

| 시점 | 훅 | 하는 일 |
|---|---|---|
| 세션 시작 | `SessionStart` | 임시 기록 파일 생성 + 이전 세션에서 못 끝낸 기록이 있으면 먼저 정리 |
| 매 턴 | `Stop` | 그 턴의 대화를 임시 파일에 기계적으로 append (AI 판단 없음) |
| 세션 종료 (best-effort) | `SessionEnd` | 헤드리스 `claude -p` 호출로 태그/상태 분류 → 정리된 문서로 저장 → 태그트리(`INDEX.md`) 갱신 → git commit/push |

`SessionEnd`가 확실히 실행된다는 보장이 없어서(예: 세션이 방치되다 자동
종료되는 경우), `Stop` 훅으로 계속 누적 저장해두고 **다음 `SessionStart`
때 처리 안 된 기록을 발견하면 그때 마저 정리**합니다. 이 이중 구조 덕분에
데이터가 사라지는 일은 없고, 정리되는 시점만 상황에 따라 달라집니다.

용어에 대해: 저희가 쓰는 "waypoint"는 Claude Code 기본 기능인
`/checkpoint`(파일 편집 되돌리기)와는 무관합니다. 헷갈리지 않게 이 도구
안에서는 "체크포인트" 대신 항상 "waypoint"라는 용어를 씁니다.

## 폴더 구조

```
waypoints/
  .tmp/                  # 진행 중인 세션의 임시 기록 (git에는 안 올라감)
  tags/
    <프로젝트>/<태그>/<날짜-시간>-<제목>.md
  INDEX.md               # 태그트리 — 전체 현황을 한눈에 보는 인덱스
```

## 다른 프로젝트에 설치하기

이 저장소는 그 자체로 "설치 가능한 패키지"입니다. 다른 프로젝트에서도
쓰고 싶다면:

1. `.claude/settings.json`, `.claude/scripts/`, `.claude/skills/waypoint/`
   를 그 프로젝트 저장소로 그대로 복사합니다.
2. 그 프로젝트에 이미 `.claude/settings.json`이 있다면 `hooks` 항목만
   병합합니다 (덮어쓰지 마세요).
3. `python3`, `git`, `claude` CLI가 해당 환경에서 실행 가능해야 합니다.

## 알려진 한계 (테스트 전 솔직한 공지)

- `SessionEnd`가 idle 타임아웃으로 인한 컨테이너 회수 시에도 확실히
  실행되는지는 공식 문서에 명시되어 있지 않습니다. 위에 설명한 안전망
  (다음 `SessionStart` 복구)이 이를 보완합니다.
- 훅 안에서 `claude -p`로 태그 분류를 호출하는 부분은 실제 다양한
  세션에서 아직 충분히 검증되지 않았습니다. 분류가 실패하면 원문을
  "미분류" 태그로 그대로 보존하도록 만들어뒀지만(데이터 유실 방지),
  실사용하면서 프롬프트나 타임아웃 값을 조정해야 할 수 있습니다.
- Claude Code 훅의 정확한 transcript 스키마는 버전에 따라 달라질 수
  있어서, 파싱 로직(`lib_common.py`)이 방어적으로 짜여 있긴 하지만
  실제 사용 중 조정이 필요할 수 있습니다.
